basic monitor test v. 1.2; branch: touch

Web application for basic monitor test.

The web site consists of several pages for testing colors (black, white, red, green, blue) and page with grid, for testing geometry. Each page allows for color adjustment (via mouse wheel or touch gestures), or change of the grid dimensions.

(mouse wheel/touch-swipe to change, 'i' to toggle info box, f/F11 to toggle full screen)
